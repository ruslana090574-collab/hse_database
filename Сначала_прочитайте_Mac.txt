1. Что открыть сначала

1. Распакуйте Шагеева_РР-ЛР.ZIP двойным щелчком в Finder. Переместите распакованную папку в «Документы». Открывайте файлы из папки, а не из окна просмотра ZIP.

2. Откройте Шагеева_РР_Страховая_компания.odb через Finder или LibreOffice → Файл → Открыть. Формат .odb — это Base, его не нужно и нельзя просто переименовывать в .accdb.

3. Для таблиц, запросов и форм внешняя Firebird и Java не нужны: база встроена в файл. Макросов в работе нет. Готовые PDF можно просмотреть через «Просмотр» macOS.

4. В исходном задании LMS требуется Access. До отправки согласуйте с преподавателем замену на LibreOffice Base. В отчёте эта замена указана открыто.

2. Посмотреть базу и запросы

1. Слева нажмите «Таблицы» (Tables). Client — клиенты, Policy — полисы, PolicyService — выбранные услуги; справочники и дополнительные таблицы описаны в отчёте.

2. Чтобы увидеть поля и ключ, щёлкните таблицу правой кнопкой мыши / двумя пальцами по трекпаду и выберите «Изменить» (Edit). Для схемы: «Сервис → Связи» (Tools → Relationships).

3. Слева выберите «Запросы» (Queries). Откройте запрос 05 двойным щелчком: должно быть 8 клиентов, у последних трёх — 0 полисов за текущий год.

4. Откройте запрос 10 или 11. Введите DateStart = 2026-01-01, DateEnd = 2026-12-31. Если локализация ожидает иной формат даты, используйте 01.01.2026 и 31.12.2026. Границы включаются.

5. Запрос 12 должен вернуть двух лидеров — агентов 1 и 2, по 3 полиса. Запрос 13 показывает среднюю стоимость: 329,88 руб. после денежного округления.

6. Запросы используют текущий год компьютера. Учебные полисы относятся к 2025 и 2026 годам, поэтому в другом календарном году ожидаемые числа изменятся.

3. Формы и ввод данных

1. Откройте «Формы» (Forms) → 03_Клиенты_просмотр. Переключайте клиентов нижними кнопками навигации; выбирайте строку полиса в подформе, чтобы увидеть его услуги.

2. Для добавления клиента используйте 02_Клиенты_регистрация; для исправлений — 01_Клиенты_редактирование. Паспорт вводится как 9 цифр; ФИО — латиницей; пол выбирается из списка.

3. Для оформления используйте 04_Оформление_полиса. Перейдите на новую запись кнопкой со звёздочкой на панели навигации. Клиента, страну и договор агента выбирайте из списков.

4. Укажите дату оформления, начало и конец. Срок должен быть не менее 7 дней, паспорт — действовать до конца поездки, клиент — быть совершеннолетним на дату оформления.

5. Сохраните родительскую запись переходом на другую запись / штатной кнопкой сохранения записи, затем выберите услуги в подформе. Автоматический номер, покрытие, курс, коэффициент, цена услуги и дата тарифа заполняются базой; вручную их вводить не требуется.

6. В списке новой услуги указана текущая цена, а в отдельном столбце хранится договорная цена на дату полиса. В просмотре истории показана сохранённая цена.

4. Отчёт Base и Java — только если понадобится

1. Слева выберите «Отчёты» (Reports) → 01_Продажа_полисов_прошлый_год. Ожидаемый итог: 5 полисов и 1 172,00 руб. Для просмотра без дополнительных настроек откройте Документы/Продажи_прошлый_год_Base.pdf.

2. Если именно Report Builder сообщает, что нет Java: установите JDK 21 с официального https://adoptium.net/. Для Apple Silicon выберите macOS aarch64, для Intel — macOS x64; архитектура должна совпадать с LibreOffice.

3. Затем откройте LibreOffice → Настройки (Preferences) → LibreOffice → Дополнительно (Advanced), включите использование Java и выберите установленную среду. Полностью завершите LibreOffice через ⌘Q и откройте снова. Это не требуется для просмотра готового PDF.

5. Подключить Calc и шаблоны Writer к базе на вашем Mac

1. Откройте LibreOffice → Настройки (Preferences) → LibreOffice Base → Базы данных (Databases). Нажмите «Создать… / New» для регистрации источника; это не создание новой пустой базы.

2. Выберите Шагеева_РР_Страховая_компания.odb в распакованной папке. Имя регистрации задайте точно HSE_INSURANCE. Сохраните настройку. Это нужно один раз: облачный путь к файлу на Mac не используется.

3. Откройте Документы/Анализ_полисов.ods. На листе «БД_Источник» выберите любую ячейку диапазона ПолисыИзБазы и выполните «Данные → Обновить диапазон» (Data → Refresh Range). Источник — запрос 09.

4. На листе «Параметры» задайте отчётный период. На листах «Агенты» и «Итоги» пересчитаются количество, выручка, средний полис и комиссия. Контроль: 8 полисов и 2 639,00 руб. Если добавили новые строки в БД, расширьте формулы и диапазоны анализа вслед за источником.

5. Для готовых документов ничего генерировать заново не нужно: Документы/Полисы_слияние содержит 13 полисов, Документы/Договоры_слияние — 4 договора.

6. Для повторного слияния откройте Полис_шаблон.odt или Договор_шаблон.odt → «Сервис → Мастер рассылки» (Tools → Mail Merge Wizard). Выберите HSE_INSURANCE и запрос 19 для полиса / 20 для договора. Сохраните сформированные документы отдельными файлами.

7. Текст в шаблонах может выглядеть как имена полей — это нормально. В готовых файлах слияния вместо них уже подставлены значения из базы.

6. Что сдавать

1. Откройте Отчёт_Шагеева_РР.pdf и просмотрите содержание и изображения. DOCX оставлен для правок в Writer; на титульном листе уже указаны ваши ФИО и группа.

2. После согласования формата Base загрузите Шагеева_РР-ЛР.ZIP в LMS. В нём находятся отчёт, база, формы и отчёт внутри базы, анализ, шаблоны и результаты слияния, SQL и контрольные результаты.

3. Сначала сохраните локальную копию исходного ZIP. Если изменяете базу или отчёт перед сдачей, обновите содержимое архива, чтобы проверялась та же версия, которую вы открывали.
